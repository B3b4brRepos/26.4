# In-Game Music Player (Minecraft 26.3, Fabric)

Open the player with **M** or by typing **/music** in chat.

- **Streaming**: powered by Lavaplayer. Search YouTube / YouTube Music / SoundCloud with the YT / YTM / SC button, or paste a YouTube, SoundCloud, Bandcamp or direct audio link. Local MP3 / OGG / WAV files also work.
- **Lyrics**: fetched from LRCLIB (or put a `.lrc` next to a local file). Shown in the Lyrics tab and the top HUD pill, plus
  - **2D lyrics**: the current line big above the hotbar (Opts > 2D),
  - **3D lyrics**: each line floats in the world in front of you (Opts > 3D, distance with - / +).
- Audio plays through Minecraft's own OpenAL.
